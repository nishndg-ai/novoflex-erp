# NOVOFLEX AI Assistant

## Version

1.0

---

# Objective

NOVOFLEX AI Assistant is an enterprise intelligence layer integrated throughout the ERP.

It is not a chatbot.

It is a manufacturing assistant capable of helping users perform ERP operations, understand data, identify issues and recommend actions while respecting role-based permissions.
