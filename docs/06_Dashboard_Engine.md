# NOVOFLEX Dashboard Engine

## Version

1.0

---

# Objective

The Dashboard Engine provides configurable, role-based, real-time dashboards for all users of NOVOFLEX ERP.

Dashboards shall be generated from metadata and business rules instead of custom programming.
