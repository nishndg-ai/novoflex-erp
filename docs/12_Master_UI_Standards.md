# Master UI Standards

Every master page shall have:

## Toolbar
- Add
- Edit
- Delete
- Restore
- Import Excel
- Export Excel
- Print
- Refresh
- History
- Help

## Search
- Quick Search
- Advanced Filter

## Grid
- Server Pagination
- Sorting
- Column Resize
- Column Reorder
- Hide/Show Columns
- Frozen Columns
- Multi Select
- Bulk Delete
- Bulk Export

## Form
- Dynamic
- Metadata Driven
- Validation
- Lookup
- Auto Complete
- Responsive
